# MasterWriter 开源项目 · 短视频讲解脚本

> 定位：约 5–8 分钟 | 口播 + 录屏操作 | 建议分 4 段录
> 使用本项目当前版本：FastAPI + Agent Pipeline + 模板系统 + Word/PDF 导出

---

## 第 1 段 · 开场：我们解决的问题（约 60 秒）

**口播（可加字幕）：**

> 写毕业论文、课程论文的时候，你最烦的是什么？
>
> 第一，**格式**。宋体小四、1.5 倍行距、首行缩进两字符、三级标题黑体，这些学校要求记不住也不愿意记，写完了还得手动调半天格式。
>
> 第二，**质量**。让 AI 直接写一篇论文，出来的东西结构散乱、前后不连贯，根本没法用。
>
> 第三，**模板**。每个学校、每门课的格式要求都不太一样。
>
> MasterWriter 就是解决这三件事的：一个**完全本地运行**的 Web 工具——不需要服务器、不需要部署，Python 一键启动，浏览器里就能用。而且它是**模型无关**的，OpenAI、通义、Kimi、DeepSeek，或者你自己搭的任意 OpenAI 兼容接口，填个地址就能用。

**录屏：** 展示项目目录 + README 标题页（可滚动几秒）。

## 第 2 段 · 启动方式（约 40 秒）

**录屏 + 口播：**

> 启动非常简单，只需要一条命令：
>
> ```bash
> python start.py
> ```
>
> 它会自动检查依赖、安装缺失的包、启动服务，然后自动打开浏览器，地址是 `http://127.0.0.1:8765`。
>
> 如果你用 Git 拉下来：
>
> ```bash
> git clone <仓库地址>
> cd master-writer
> python start.py
> ```

**录屏：** 终端运行 `python start.py`，等待服务起来，浏览器自动弹出来。

## 第 3 段 · 设计与实现（约 90 秒）

**口播（配合代码截图或目录树）：**

> 这个项目在技术上做了几个我觉得还比较讲究的设计：

**1. Agent Pipeline（写作编排）**
> 整个写作流程不是"一把梭"，而是拆成小技能（Skill）：生成大纲、写引言、写正文、写结论、生成摘要、生成参考文献。每个技能就是一个 YAML 文件，里面是写好的提示词。它们可以**编排成流水线**——内置了"一键成文"管线：大纲 → 循环生成各章正文 → 摘要 → 参考文献。
>
> 而且这个流水线是**数据驱动**的，用户可以自己定义流程，后面做拖拽式编排 UI 的时候后端直接就支持了。

**2. 模板三通道**
> 格式问题的核心是模板。我们支持三种方式：
> - 内置模板（本科论文/课程论文/默认格式）
> - **上传你自己的 Word 文档**，后台自动解析它的字体、行距、页边距、标题样式
> - 或者**手动定义**，只填你关心的几项，其他自动用默认值

**3. 文档引擎**
> 导出 Word 的时候，自动生成目录（在 Word 里打开会自动更新页码）、格式化中英文摘要、参考文献按 GB/T 7714 规范清洗导出、四五六级标题自动折叠成规范的三级标题。

**4. 模型层**
> 支持任意 OpenAI 兼容端点，自定义 Base URL + API Key + 模型名，还带一个"测试连接"按钮，配置后立刻验证能不能通。没有 Key 的时候还有本地 Mock 模式，把全流程演示走通。

**5. 工程化**
> 40 个单元测试 + 端到端 API 测试，每次改动全量回归；SQLite 本地存储，重启不丢数据。

**录屏：** 展示目录树 `backend/app/agent/`、一个 skill YAML 文件、模板 JSON；或直接口头带过配代码截图。

## 第 4 段 · 演示：写一篇论文（约 120 秒，重点段）

**场景 A：一键成文**

> 我们新建一篇论文，输入题目，选默认模板，然后直接点"**一键成文**"。
>
> 它会自动生成大纲、逐章写正文、生成摘要和参考文献。可以看到流式输出，边生成边显示。
>
> 如果觉得某一部分可以了，随时点右上角的"**暂停生成**"——已经生成的内容会**自动保存成章节**，不会白干。

**录屏：** 新建论文 → 一键成文 → 滚动看流式输出 → 暂停 → 刷新看章节已保存。

**场景 B：格式与导出**

> 生成完之后，我们点"导出 Word"。打开看看：
> - 开头是自动生成的**目录**，章节标题都有了（Word 里右键更新域还能出页码）
> - 正文的标题、字体、行距都是学校要求的格式
> - 参考文献是悬挂缩进、规范的 [1] [2] 编号
>
> 再点"导出 PDF"，本机用 Word 转成 PDF，也是完全排好版的。

**录屏：** 导出 Word → 用 Word 打开展示目录/格式/参考文献 → 导出 PDF 展示。

**场景 C：模板自定义（如果时间够再演）**

> 如果你的学校格式特殊，可以上传学校的 Word 模板，系统自动解析出格式；也可以手动定义，改字体、字号、行距、标题样式，一键应用到所有导出。

**录屏：** 模板管理 → 手动定义，改个字号/行距 → 新建论文选这个模板 → 导出确认。

## 附录 B · 常见翻车点

| 风险 | 应对 |
|------|------|
| Mock 模式生成太快，暂停按钮来不及展示 | 用真实模型（deepseek/qwen 等）演示暂停 |
| 首次导出 PDF 要启动 Word 较慢 | 演示前先手动导一次，避免当场卡顿 |
| 一键成文耗时较长（真实模型） | 可以先跑生成大纲，或中途点暂停展示"部分保存" |
| 端口 8765 被占用 | `netstat -ano | grep 8765` 找到 PID 结束，或改 `backend/app/config.py` 的 PORT |
